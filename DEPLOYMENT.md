# Deployment Guide

## 1. Publish to GitHub

1. Sign in to GitHub as **hanzla-codes**.
2. Create a new **public** repository (for example, `personal-portfolio`).
3. Upload/push the contents of the `personal-portfolio` folder so `index.html` is at the repository root.
4. Commit the files.
5. Copy the public repository URL and paste it into `SUBMISSION.md`.

## 2. Deploy on Vercel

1. Sign in to Vercel and connect the same GitHub account.
2. Choose **Add New → Project** and import the portfolio repository.
3. The project is static, so no framework/build command is required.
4. Deploy it.
5. Open the generated Vercel URL and test navigation, project links, and mobile layout.
6. Paste the live URL into `SUBMISSION.md`.

## 3. Create the LinkedIn Post

1. Open `LINKEDIN_POST.md`.
2. Replace the GitHub and live website placeholders with the real links.
3. Add a screenshot of the portfolio.
4. Publish the post on Muhammad Hanzla's LinkedIn account.
5. Copy the post URL into `SUBMISSION.md`.
