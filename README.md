# Muhammad Hanzla — Personal Portfolio

A responsive, dark/minimal personal portfolio built with **plain HTML, CSS, and JavaScript**. It is designed to present Muhammad Hanzla as a junior MERN stack / frontend developer with visible SEO and digital marketing skills.

## Highlights

- Dark professional UI with gold/amber accents
- Fully responsive navigation and layout
- Smooth reveal animations and active navigation
- Skills grouped across MERN, frontend, SEO/marketing, and developer tooling
- Four portfolio cards: 1378store, EduPlay, Digital Analog Clock, and this portfolio
- Working GitHub, LinkedIn, demo, and email links where provided
- Contact form validation that opens the visitor's email app
- No libraries, frameworks, or build step used by the portfolio itself

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

> React, Node.js, Express.js, MongoDB, SEO, etc. are listed as Muhammad Hanzla's skills/project technologies. The portfolio website itself remains strictly plain HTML/CSS/JS.

## Run Locally

Open `index.html` directly in a browser, or serve this folder with any simple static server.

## Customize Before Publishing

1. **Profile photo:** replace `assets/images/avatar.svg` with a real photo and update the `<img>` path in `index.html` if the filename changes.
2. **CV:** add the real PDF as `assets/Muhammad-Hanzla-CV.pdf`, then change the Download CV button from its `#` placeholder to `assets/Muhammad-Hanzla-CV.pdf` and add the `download` attribute.
3. **Missing project repositories:** only add GitHub links for EduPlay or Digital Analog Clock if real repository URLs are available.
4. Update `SUBMISSION.md` after GitHub/Vercel/LinkedIn publishing.
